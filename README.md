# github-practice

GitHub 功能实操练习仓库：从第一次 commit 走到 PR 合并、Actions 自动测试与 Pages 上线。

## 使用方法（分支版本）

```powershell
python src/calc.py
```

```python
from src.calc import add, subtract, multiply, divide

add(1, 2)       # 3
subtract(5, 3)  # 2
multiply(3, 4)  # 12
divide(8, 2)    # 4.0
```
